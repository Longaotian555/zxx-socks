# zxx-socks

适用于 Debian / Ubuntu 的 SOCKS5 一键部署与管理脚本。

使用 MicroSOCKS 提供代理服务，通过 systemd 管理进程和开机启动，并提供 `s5` 命令打开管理菜单。

## 功能

- 一键安装 SOCKS5 代理。
- 自动生成随机账号、密码和空闲端口。
- 自动查询服务器公网 IPv4，显示连接信息。
- 支持查看状态、启动、停止和重启服务。
- 支持单独更换账号密码或端口。
- 支持本机代理连接检测和查看服务日志。
- 支持卸载代理服务及配置。

## 系统要求

- Debian / Ubuntu。
- 系统使用 systemd，支持 `apt-get`。
- 使用 root 用户在交互式 SSH 终端中运行。
- 服务器能够访问软件源、GitHub 和检测网站。
- 服务器具备可供客户端连接的公网 IPv4，或已配置对应的端口转发。

> 本脚本监听 IPv4，提供 TCP 代理，不支持 SOCKS5 UDP 转发。

## 安装

连接 VPS 的 SSH 终端，以 root 用户执行。

如果当前不是 root，可以先运行：

```bash
sudo -i
```

安装下载工具：

```bash
apt-get update && apt-get install -y curl ca-certificates
```

下载脚本、检查语法并打开菜单：

```bash
curl -fsSL https://raw.githubusercontent.com/Longaotian555/zxx-socks/main/socks5.sh -o /root/socks5.sh && bash -n /root/socks5.sh && bash /root/socks5.sh
```

出现菜单后，输入 `1` 安装。

安装完成后，会显示服务器地址、端口、账号和密码，并执行一次本机代理连接检测。

以后使用 root 执行以下命令，即可打开管理菜单：

```bash
s5
```

## 管理菜单

| 选项 | 功能 |
| --- | --- |
| 1 | 安装 / 修复 SOCKS5，保留已有配置 |
| 2 | 查看连接信息 |
| 3 | 随机更换账号和密码 |
| 4 | 随机更换端口 |
| 5 | 检测本机代理连接 |
| 6 | 查看服务状态 |
| 7 | 重启代理 |
| 8 | 停止代理 |
| 9 | 启动代理 |
| 10 | 卸载代理服务及配置 |
| 11 | 查看近期日志 |
| 0 | 退出菜单 |

首次安装时，脚本会在 `10000–65000` 范围内随机选择一个空闲端口。

已有配置时，选择 `1` 会保留账号、密码和端口。需要重新生成时，请选择 `3` 或 `4`。

## 放行端口

安装后，需要在以下位置放行脚本显示的 **TCP 端口**：

1. VPS 服务商控制台中的云安全组或网络防火墙。
2. VPS 系统中已经启用的防火墙。

例如，代理端口为 `12345`，且服务器使用已经启用的 UFW：

```bash
ufw allow 12345/tcp
ufw status
```

请将 `12345` 替换为菜单显示的实际端口。

脚本不会自动修改防火墙规则。更换端口后，需要放行新端口，并按需删除旧端口规则。

## 客户端连接

在支持 SOCKS5 的客户端中填写：

| 项目 | 内容 |
| --- | --- |
| 代理类型 | SOCKS5 |
| 服务器地址 | VPS 的公网 IPv4 |
| 端口 | 菜单显示的端口 |
| 用户名 | 菜单显示的账号 |
| 密码 | 菜单显示的密码 |

菜单同时会显示参考链接：

```text
socks5://账号:密码@服务器公网IP:端口
```

是否支持直接导入链接取决于客户端。无法导入时，请手动填写连接信息。

如果公网 IP 自动查询失败，请手动填写 VPS 的真实公网 IPv4。使用端口转发时，应填写客户端实际连接的公网地址和外部端口。

## 检测连接

打开菜单：

```bash
s5
```

选择 `5`，检测服务器本机的 SOCKS5 认证、通过代理解析域名以及 HTTPS 出站连接。

检测成功会显示代理出口 IPv4。

**本机检测成功后，还需要从外部客户端验证连接，以确认公网地址、端口和防火墙规则正确。**

也可以在自己的电脑或另一台服务器上执行以下命令。请先替换服务器公网 IP、端口、账号和密码：

```bash
curl --noproxy "" \
  --proxy "socks5h://服务器公网IP:端口" \
  --proxy-user "账号:密码" \
  --connect-timeout 10 \
  --max-time 30 \
  https://api.ipify.org
```

成功时会返回代理的出口 IPv4。

## 更新管理脚本

仓库中的 `socks5.sh` 更新后，以 root 执行：

```bash
curl -fsSL https://raw.githubusercontent.com/Longaotian555/zxx-socks/main/socks5.sh -o /root/socks5.sh && bash -n /root/socks5.sh && bash /root/socks5.sh
```

脚本会更新本机的 `s5` 管理命令。

如需重新安装依赖并应用当前版本的服务配置，在菜单中选择 `1`。已有账号、密码和端口会保留。

## 卸载

运行：

```bash
s5
```

选择 `10`，输入 `y` 确认。

卸载会停止代理，取消代理服务的开机启动，并删除服务配置和账号配置。

`s5` 管理命令及已安装的软件包会保留，方便以后重新安装。

## 常见问题

### 提示需要 root

先执行：

```bash
sudo -i
```

然后重新运行安装命令或 `s5`。

### 提示需要 systemd

该脚本需要运行 systemd 的 Debian / Ubuntu 系统。未运行 systemd 的容器或精简环境无法直接使用。

### 提示 `unexpected end of file`

通常说明脚本内容没有复制完整。

检查仓库中的 `socks5.sh` 是否完整，最后一行应为：

```bash
main "$@"
```

保存后重新下载运行。

### 本机检测成功，但客户端无法连接

请检查：

- 客户端填写的公网 IP 和端口是否正确。
- 云安全组是否放行对应的 TCP 端口。
- 服务器防火墙是否放行对应的 TCP 端口。
- 客户端是否选择 SOCKS5，并正确填写账号和密码。
- 使用端口转发时，外部端口是否映射到脚本显示的端口。

### 本机检测失败

在菜单中选择 `6` 查看服务状态，选择 `11` 查看近期日志。

同时检查服务器出网、DNS 和检测网站是否可访问。检测失败也可能由外部检测网站暂时不可访问引起。

### 更换账号或端口后无法连接

更换账号密码后，需要更新客户端的认证信息。

更换端口后，需要更新客户端端口，并在云安全组和服务器防火墙中放行新端口。

## 文件位置

| 文件 | 用途 |
| --- | --- |
| `/usr/local/bin/s5` | 管理脚本 |
| `/etc/my-socks5.conf` | 端口、账号和密码配置 |
| `/etc/systemd/system/my-socks5.service` | systemd 服务配置 |

服务名称：`my-socks5`。

## 使用说明

SOCKS5 本身不提供流量加密。涉及敏感数据时，请使用 HTTPS 等提供加密的应用协议。

请妥善保存账号和密码，避免将包含连接信息的截图或配置文件公开。
